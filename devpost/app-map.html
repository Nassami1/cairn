The claim

    Follow one click

    1. An example chip calls handleExample in src/App.tsx, which sets the claim and calls run.
    2. run opens a stream via streamVerification in src/lib/api.ts — a POST, because EventSource cannot send a body.
    3. POST /api/verify reaches handleStream in server/routes/verify.js, which applies the rate limit and cache.
    4. verifyClaim in server/engine/verify.js owns the five stages and emits them as SSE events.
    5. The engine calls retrieveCandidates, examineSource, weighEvidence and composeVerdict in that order.
    6. App.applyResult receives the result event and renders Dossier → VerdictCard + Ledger.

    Project-grounded practice

    01 · trace a number Pick the score on screen, open weigh.js, and find the four factor numbers that produced it. Say the formula out loud in one sentence.
    02 · move a weight Change WEIGHTS.agreement from 0.32 to 0.45 and independence from 0.24 to 0.11 (keep the sum at 1). Rebuild, rerun the Great Wall claim, and note which way the score moves. Revert.
    03 · add a cue Add a refutation phrase you have actually seen in a fact-check (“baseless”, “no credible evidence”) to REFUTE_PATTERNS, run npm test, and decide whether it changed a real claim.
